# Support

SyntraLang is an early-stage open-source project. Support is currently community/maintainer-led and best-effort.

## Where to ask

- Bug reports: https://github.com/gd2bk1ng/syntra_lang/issues
- Pull requests: https://github.com/gd2bk1ng/syntra_lang/pulls
- Documentation: start with the repository README and `docs/` directory.

Before opening an issue, check the Getting Started guide, FAQ, and existing issues.

## What to include

For build/tooling problems, include your operating system and architecture, `rustc --version`, `cargo --version`, commit SHA, exact command, relevant output, and a minimal reproduction.

For language/parser problems, include a small SyntraLang source example and expected versus actual behavior.

## Privacy and security

Do not post passwords, API keys, access tokens, private source code, personal data, or vulnerability details in public issues. See [SECURITY.md](SECURITY.md) for vulnerability reporting.

## Expectations

There is no guaranteed response time or commercial support agreement. Please be respectful, specific, and patient.
