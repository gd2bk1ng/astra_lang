# SyntraLang Wiki

Welcome to the SyntraLang project wiki.

SyntraLang is an experimental, intent-oriented language foundation exploring explicit representations of goals, effects, uncertainty, and governance alongside ordinary computation.

> **Status:** pre-alpha. The project does not yet provide a complete compiler, interpreter, or production execution runtime.

## Core principles

- Syntax records intent; it does not grant authority.
- Static verification and runtime enforcement are separate.
- Source provenance and ownership boundaries matter.
- Security-sensitive transitions require explicit invariants and adversarial tests.
- Documentation distinguishes implemented behavior from future design.
